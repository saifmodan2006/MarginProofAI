# Implementation plan

1. Establish the React/Vite and FastAPI monorepo, SQLite migration, fictional workspace, and accessible financial interface.
2. Persist CSV/XLSX previews, validate mappings and references, commit accepted rows transactionally, and retain source lineage.
3. Calculate currency-isolated Decimal reconciliation, revenue, expenses, labor costs, unbilled estimates, and project contribution margins.
4. Persist findings and evidence, preserve investigation state on recalculation, and add source exploration and charts.
5. Add actions, hypothetical scenarios, a deterministic analytical question interface, and real report downloads.
6. Verify financial edge cases, API workflows, frontend build, browser behavior, and document remaining limits.

The implementation deliberately stops at a development-only, single fictional workspace boundary. Production identity, tenant authorization, normalized accounting entities, and deployment hardening require a separate milestone before public hosting.
